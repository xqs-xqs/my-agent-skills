# 第 8 讲：检索增强生成（RAG）与 Agent 记忆

【第 1 页】课程目标
理解 LLM 的知识局限，掌握 RA-LLM 的基本架构、检索器类型、检索前/检索后技术，理解 RAG 与 Agent 长期记忆的关系。

【第 2 页】LLM 的局限
- 幻觉：模型生成看似合理但与事实不符的内容。
- 领域知识不足：预训练语料对专业领域覆盖有限。
- 知识过时：参数中的知识截止于训练时间。
- 隐私：私有数据无法也不应写入公开模型参数。

【第 3 页】参数化知识 vs 非参数化知识
参数化知识存储在模型权重中，更新需要重新训练或微调；非参数化知识存储在外部语料库/数据库中，可随时增删改。RAG 的思想是把"闭卷考试"变成"开卷考试"：模型回答前先查资料。

【第 4 页】RA-LLM 架构
必要组件：检索器（Retriever）、生成器（Generator）、整合（Integration）方式。
可选组件：检索前处理（Pre-retrieval）与检索后处理（Post-retrieval）。
经典 RAG（Lewis et al., 2020）= DPR 检索器 + BART 生成器，端到端联合训练查询编码器与生成器。
In-Context RALM：不改模型，直接把检索到的文档拼接在输入前面，适用于黑盒 API 模型。

【第 5 页】稀疏检索器
TF-IDF：词频 × 逆文档频率。BM25：在 TF-IDF 基础上引入词频饱和与文档长度归一化：
score(D,Q) = Σ IDF(q_i) · f(q_i,D)·(k1+1) / (f(q_i,D) + k1·(1 - b + b·|D|/avgdl))
优点：无需训练、可解释、对精确关键词匹配强；缺点：无法处理同义词与语义匹配。

【第 6 页】稠密检索器
DPR：有监督训练，问题编码器与段落编码器分离（双编码器），用 in-batch negatives 对比学习，相似度为向量内积。
Contriever：无监督对比学习，查询与文档共享同一编码器，通过随机裁剪构造正样本对，无需标注数据。
优点：语义匹配能力强；缺点：需要训练、索引成本高、对罕见实体不如 BM25。

【第 7 页】其他检索器
上下文学习检索器：为 In-Context Learning 挑选示例，如 Prompt Retriever、CEIL（考虑示例间多样性与组合）。
搜索引擎作检索器：直接调用 Web 搜索，时效性好，但结果不可控。

【第 8 页】检索前技术
查询重写（Query Rewriting）：用 LLM 将用户原始问题改写为更适合检索的形式。
HyDE：先让 LLM 生成一篇"假设文档"作为答案草稿，再用该假设文档的向量去检索真实文档。
query2doc：用 LLM 生成伪文档并与原查询拼接，扩展查询，提升稀疏和稠密检索效果。

【第 9 页】检索后技术
重排（Re2G）：先粗检索再用交叉编码器精排。
压缩（RECOMP）：将检索文档压缩为摘要（抽取式/生成式），减少上下文长度。
纠错（CRAG）：评估检索质量，置信度低时触发 Web 搜索补充或丢弃。
精炼（Refiner）：抽取与问题相关的内容并重新组织。

【第 10 页】从 RAG 到 Agent 记忆
参数学习的问题：灾难性遗忘与涟漪效应（修改一个事实会影响相关事实）。
外部证据可以覆盖参数记忆：当检索内容与参数知识冲突时，模型往往倾向采用上下文证据。
短期记忆 = 上下文窗口；长期记忆 = 外部存储。
RAG 可以看作"只读的长期记忆"；Agent 记忆还需要写入与更新。
海马体索引理论：海马体存储的是指向新皮层记忆的索引，支持关联检索（如 HippoRAG 借鉴此思想用知识图谱 + PPR 做多跳检索）。

【第 11 页】长期记忆类型
情景记忆：记录发生过的事件流，如 Generative Agents 的记忆流（按近因、重要性、相关性打分检索）。
语义记忆：从经历中抽象出的知识，如通过反思（Reflection）归纳高层结论。
程序记忆：如何做事的技能，如 Voyager 的技能库（将可执行代码存入库中按描述检索复用）。

【第 12 页】学习的统一视角
Agent 的"学习"可以发生在多个层面：微调权重；跨任务优化提示（APE）；改进自身代码库；把事件写入记忆供日后检索；自我反思（Reflexion，将失败经验写成文字反馈）；组合多种方式（BetterTogether，交替优化提示与权重）。

【第 13 页】记忆管理系统
MemGPT：借鉴操作系统虚拟内存，分层存储（主上下文 / 外部上下文），由 LLM 通过函数调用自行换入换出。
Mem0：从对话中抽取候选记忆，与已有记忆比对后由 LLM 决定 ADD / UPDATE / DELETE / NOOP 四种操作。

【第 14 页】小结
RAG 解决知识时效与幻觉问题；检索器、检索前后技术决定检索质量；Agent 记忆在 RAG 基础上增加写入、更新与多类型记忆管理。
