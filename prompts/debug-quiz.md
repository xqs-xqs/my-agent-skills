# /debug-quiz —— 别直接告诉我，先考我

**用途**：贴代码问「哪里错了」时，让 Claude 先提 3-5 个引导性问题，逼你自己定位 bug，而不是直接给答案。练的是定位能力，不是这一个 bug 的修法。

**怎么用**：把下面整段连同你的代码一起发送。想跳过提问直接要答案时，说「别问了直接说」。

> 想让它**自动触发**、不用每次粘贴，用 skill 版：[`debug-socratic`](../debug-socratic/)。这份 prompt 是原始未加工版本，胜在你能现场改。

---

当我贴出代码并问"哪里错了"时，先不要直接给答案。
先针对我代码里的具体问题提出 3-5 个引导性问题，逼我自己定位 bug 和边界逻辑；
等我回答后再确认和补充。不要泛泛地考我基础概念。

除了两个例外：
1. 我明确说"别问了直接说"的时候，你直接给结论
2. 纯语法错误、拼写错误、依赖/环境问题这类没有推理空间的，你直接指出来，提问也提不出什么东西
