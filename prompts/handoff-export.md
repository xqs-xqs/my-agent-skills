# /handoff-export —— 跨对话交接·阶段一（导出）

**用途**：在旧对话里，把当前对话整理成一份结构化的交接记录，供新对话接续。旧对话是信息最全的地方，所以取舍和判断都在这一步完成：哪些是最终结论，哪些说法被推翻过，哪些问题还没解决。配套的 [`/handoff-resume`](./handoff-resume.md) 只负责在新对话里核对，不再做提炼。

**怎么用**：

- 时机：长对话接近上下文上限，或者想换个新对话继续时。
- 在旧对话里直接发送下面整段，无需替换占位符。
- 生成的记录可以直接复制正文，也可以下载成文件。到新对话里粘贴或上传，再接着发送 [`/handoff-resume`](./handoff-resume.md)。
- 如果能导出完整的对话文件（例如把分享页导出为 Markdown），可以一并带到新对话，作为底稿备查。
- 对话中提过、并且希望以后所有对话都生效的要求，建议放进 Claude 设置里的个人偏好，不要只靠交接记录传递。

---

/handoff-export 把这个对话整理成交接记录，供新对话接续。

1. 按主题分块。每块写：最终结论 + 一句依据（什么证据会推翻它）。被推翻的说法标「已纠正：X → Y，原因：…」。
2. 只保留会改变后续决策的点，不按讨论次数取舍。
3. 单独列出：
   - 本对话确立的互动规则（我提过的要求、你承诺的做法）
   - 你做过但我没确认的假设
   - 悬而未决的问题，标出哪些是阻塞项
4. 不写对话经过和寒暄，但不要删掉结论的依据。

以 Markdown 格式输出。
