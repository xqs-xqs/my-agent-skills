# 导读页面的版式与组件

制作 HTML 导读页面时读这一份。`assets/page-template.html` 里有全部样式和每个组件的示例，从它开始改，不要从零写样式。

## 版式

- **左侧目录，右侧一栏正文。** 目录在宽屏下固定在左边，窄屏下变成顶部的一排标签。正文宽度约 42 个汉字，读起来不累。
- **章节带编号。** 导读是学习路径，顺序本身就是信息。编号用等宽小字放在标题前。
- **页首只有标题、一句说明、几个事实**（语言、规模、依赖等）。不做大幅封面。
- **打开即完整。** 所有内容加载后直接可见，不依赖滚动触发的动画。

## 颜色

- 中性色带一点冷色调，背景、卡片、正文、次要文字、分隔线各一个变量。
- 一个强调色，只用于链接、章节编号和步骤序号。
- **一组语义色，只表示一个维度**，例如“哪个角色在行动”。每个取值配一个前景色和一个浅底色。三到五个取值为宜；再多就该换维度或合并。同一套颜色贯穿图、正文标签和运行输出。
- 成功和失败另用绿色和红色，并且同时用文字说明，不单靠颜色区分。
- 所有颜色定义为 `:root` 上的变量，深色模式只重定义变量；组件里不写死颜色。模板已按这个结构写好。

## 字体

- 正文用无衬线体，中文落到系统字体（苹方、微软雅黑、思源黑体）。
- 代码、命令、终端输出、章节编号用等宽体。
- 字号层级固定：页标题、章标题、小节标题、正文、说明文字。强调用加粗，不另起字号。

## 组件

模板里每个都有示例，类名如下。

| 组件 | 类名 | 用在哪 |
|---|---|---|
| 概念卡片 | `.concepts` `.concept` | “基础概念”一节：术语、英文名、一句定义、一句类比 |
| 提示条 | `.note`（警示用 `.note.warn`） | 纠正误解、说明数据来历、指出局限。一页不超过四五处 |
| 图 | `figure` `.scroll` `svg.dia` | 每个机制一张，下方 `figcaption` 写这张图要说明什么 |
| 角色标签 | `.role` 加语义类 | 正文里提到某个角色或模块时 |
| 逐行注释的输出 | `.filters` `.trace` | “读懂一次运行”：左边一行输出，右边一句说明，可按角色筛选 |
| 步骤条 | `ol.steps` | 线性流程，每步一个短标题加半句说明 |
| 表格 | `.tw` 包住 `table` | 对比、规则清单、代码地图 |
| 双栏对照 | `.ctx` | 两种状态并排，例如“完整内容”和“实际看到的内容” |
| 术语表 | `dl.gloss` | 最后一节，也用于“某语言最小词汇表” |

卡片式样式只给需要独立成块的东西（概念卡、步骤、图的容器）。正文段落不加边框。

## 画图

用手写的内联 SVG，不引入图表库。

- 用 `viewBox` 定尺寸，CSS 让它随容器缩放；外层 `.scroll` 设了最小宽度，窄屏下图在自己的容器里横向滚动，页面本身不滚。
- 线条和文字用 `currentColor`，随主题变色；语义色通过类名取变量。
- 箭头用 `<marker>`。不同颜色的箭头各定义一个 marker，不要用 `context-stroke`，部分浏览器不支持。
- 图里的文字 11 到 13 像素，一个标签两三个词；解释性的句子放到 `figcaption`。
- 对齐到网格：同一行的方框等高、等间距，成对的箭头左右各偏移相同距离。
- 每个箭头都要有标签，说明传的是什么。
- 方框里写“它做什么”，不只写名字。
- 给 `svg` 加 `role="img"` 和 `aria-label`，内容与图下说明一致。

## 逐行注释的运行输出

- 数据放在脚本里的数组中，每项是：语义类、输出原文、说明。脚本生成行并处理筛选。
- 输出原文保持真实格式，只做删减，并在上方说明这是节选。
- 输出来自替身（假模型、模拟服务）时，用一条 `.note.warn` 写明哪些是真实产生的、哪些是预先写好的。
- 筛选按钮改变的是其它行的透明度，不隐藏，读者仍能看到上下文。

## 容易出错的细节

- **id 不要重复。** 章节的 id 和组件容器的 id 用了同一个名字时，脚本会找到错误的元素，表现为内容不显示且没有报错。
- **表格要有最小宽度。** 否则窄屏下某一列会被挤成一个字一行。模板里已设置，并由 `.tw` 负责横向滚动。
- **代码块自己滚动。** `pre` 设了 `overflow-x: auto`，长命令不会撑宽页面。
- **手机宽度和深色模式各看一次。** 这两种情况最容易出问题。
